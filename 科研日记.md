2. The guide to install **HiFiLES**. 
    1. set CUDA, HIFILES_HOME, HIFILES_RUN correctly in .bashrc.
    2. use prestep.sh to let autoconf/automake to be compatible with lower versions.
    ```bash
    #/bin/bash
    autoconf -r -i
    ```
    3. replace all 'array' to 'arr' because C++ introduce array in C++11.
    4. compile for metis.h and parmetis.h file
    ```linux
    ./configure
    make
    ```
    5. modify configure_run.sh. change everything we used to correct path.In lib/ we have metis.a and parmetis.a 
    6. compile for GPU, release,and parallel version
    ```
    bash configure_run.sh
    make
    ```
    7. when we use, we need enter the path where input_file and mesh_file are in and call the HiFiLES in bin/
